# Short paper (4 pages)

The 4-page version, for academic evaluation. `acl_latex.tex` **must be compiled with
XeLaTeX**, not pdfLaTeX, because it sets Sinhala examples. In Overleaf: Menu →
Compiler → XeLaTeX.

This folder is self-contained: upload it to Overleaf on its own. The 8-page ACL
version is in `../paper/`.

Current state: 4 pages of content (§1–§4 with the discussion folded in as the final
paragraph of §4, ending at the bottom of page 4), then Limitations, Ethics,
References and seven appendices. Zero LaTeX errors, zero overfull boxes, no
undefined references, 37 references cited.

## How it differs from the 8-page version

Same results, same numbers, restructured for the page budget.

| | 8-page | 4-page |
|---|---|---|
| Related work | own section | one dense paragraph in §1 |
| Floats in body | 3 figures, 6 tables | 1 figure, 1 table |
| Discussion | own section | closing paragraph of §4 |
| Appendices | 4 | 7 |

Two wide floats will not both fit in four pages, since a `figure*`/`table*` can only
sit at a page top and page 1 gives its top to the title block. So the body keeps one
full-width results table plus one single-column figure that carries two results at
once (the metric disagreement and the floor-effect law), and the flattening figure,
the $n$-gram table, the strata table, the linkage table and the Global PIQA table all
move to appendices, which do not count against the limit.

## Provenance of the numbers

Table bodies under `tables/` and figures under `figures/` are generated by the
scripts in `../paper/tables/` and `../paper/figures/` from the frozen analysis in
`../paper/analysis/out/`. Nothing is typed by hand.

```bash
python paper/analysis/verify_claims.py        # 160 numbers in the 8-page paper
python paper_short/check_consistency.py       # short paper is a subset of those
```

The first script checks every number in the 8-page paper against the analysis
output. The second asserts that every numeric claim in this paper also appears in
that verified text, which is why this folder needs no separate checker.

If you regenerate the assets, copy them across:

```bash
python paper/tables/make_tables.py && python paper/figures/make_figures.py
cp paper/tables/tab_{extrinsic_main,ngram,strata,methods,intrinsic_joined,piqa,linkage}.tex paper_short/tables/
cp paper/figures/{figS1_metric_and_law,figS2_flattening_narrow}.pdf paper_short/figures/
```

## Watch out when editing

The body is at the page limit with no slack. Adding a sentence to §1–§4 will push
the last line of §4 onto page 5. If that happens, the quickest levers are the height
of `figS1` in `../paper/figures/make_figures.py`, the `\footnotesize` and
`\tabcolsep` on Table 1, and the float parameters set in the preamble.

Also note that `\input` breaks LaTeX's alignment scanner inside a `tabular`, so
generated table bodies are pulled in with `\rows{...}`, defined in the preamble over
the `\@@input` primitive. Use `\rows`, not `\input`, inside a table.
